# Brief template

Copy to `videos/<slug>/brief.md` and fill every slot with a decision. Replace each
adjective with a number before building.

```
GOAL:     what a restaurant operator should understand or feel, one sentence, about ONE feature
AUDIENCE: who (GM, owner, ops lead), where they see it (LinkedIn feed, Reels), sound on or off
OUTPUT:   compositions (9:16 master + which cuts), duration, fps 30, H.264 CRF 18
TIME:     seconds × 30 = N frames; BPM and frames per beat if cut to music
LOOK:     palette from theme.ts (one accent: momos red); type sizes; texture if any
MOTION:   easings and springs by token name; any value not in the token table, with reason
SHOTS:    beat ranges; ONE hero move each; hand-off to the next shot; which frames are hits
COPY:     hook line (problem first), real UI strings, captions, end card line + CTA
DATA:     each number and review: real (source) or illustrative; anonymisation applied
BANNED:   the calibration list + anything this brief adds
GENERIC:  two lines on what the generic AI version would be, and how this differs
QA:       frames to still (0, boundaries ±2, hits, last), phone check, stop rule (≥8 or 3 rounds)
```
